# Code of conduct

AutoPrepML aims to be a respectful, constructive, and inclusive project.
Participants should communicate professionally, assume good intent, explain
technical disagreements with evidence, and protect private information.

Unacceptable behaviour includes harassment, discrimination, personal attacks,
unwelcome sexual attention, threats, doxxing, and deliberate disruption.

Report a concern privately through the security contact in `SECURITY.md` or by
emailing mdshoaibuddin.chanda@gmail.com. Reports will be reviewed fairly and
confidentiality will be respected where possible.
